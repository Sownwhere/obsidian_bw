# 一、什么是突触后（postsynaptic side）

在一个突触里：

- 突触前：释放神经递质
- 突触后：接收信号（通常是树突棘）

关键结构叫：  
👉 **突触后致密区（postsynaptic density, PSD）**

里面富含：

- 受体（AMPA / NMDA）
- 支架蛋白（PSD-95）
- 信号蛋白（CaMKII 等）

# 二、突触形成（Synaptogenesis）——不是“长出来”，而是被活动塑造

## 1. 初始接触（结构阶段）
流程：

1. 轴突探索（growth cone）
2. 树突上伸出 filopodia（像触手）
3. 随机接触 → 弱连接形成

👉 这一步是**结构随机 + 分子引导**

关键分子：

- **Neuroligin（突触后）**
- **Neurexin（突触前）**
