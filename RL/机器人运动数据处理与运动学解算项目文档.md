
## 1. 项目概述

本项目是一个用于**机器人运动数据处理与运动学解算**的 Python 脚本。主要功能是将原始的动捕数据（CSV 格式）进行重采样、平滑处理，利用 Pinocchio 库进行正向运动学（FK）解算，计算各连杆的位姿和速度，最后保存为 NPZ 格式的数据集。

*   **输入**：机器人动捕原始数据（CSV 格式，包含根节点位姿和关节角度）。
*   **处理**：数据重采样（90Hz -> 60Hz）、插值、正向运动学解算、速度计算与平滑。
*   **输出**：包含位置、速度、关节名、连杆名等信息的 NPZ 文件。
*   **适用对象**：主要针对名为 `bw` 的双足机器人。
*   **应用场景**：模仿学习（Imitation Learning）、轨迹跟踪控制、运动分析。

## 2. 代码处理流程

### 2.1 主要步骤
1.  **文件加载**：
    *   支持命令行指定或自动查找最新 CSV 文件。
    *   读取 CSV 数据（前 7 列为根节点，后 12 列为关节角度）。
2.  **时间重采样 (Resampling)**：
    *   频率转换：**90Hz → 60Hz**。
    *   **位置**：线性插值 (`interp1d`)。
    *   **姿态**：球面线性插值 (`Slerp`)。
    *   **关节角**：线性插值。
3.  **运动学解算 (Forward Kinematics)**：
    *   加载 URDF 模型。
    *   构建配置向量 `q_pin`（含 Z 轴偏移）。
    *   计算关键连杆在世界坐标系下的位姿。
4.  **速度计算**：
    *   线速度：位置中心差分 + 高斯滤波。
    *   角速度：四元数差分解算 + 高斯滤波。
5.  **数据保存**：
    *   打包为字典，保存为带时间戳的 `.npz` 文件。

### 3.2 配置向量 `q_pin` 结构
总自由度 `nq = 19` (7 浮动基座 + 12 关节)。

| 索引 | 含义 | 来源 | 备注 |
| :--- | :--- | :--- | :--- |
| 0-2 | 位置 (x,y,z) | `root_data[:, 0:3]` | **Z 轴 +0.5m 偏移** |

## 4. 核心理论详解：四元数插值 (Slerp)

在数据重采样过程中，对于根节点的四元数姿态，代码使用了 **Slerp (球面线性插值)** 而非普通的线性插值 (Lerp)。

### 4.1 为什么使用四元数？
*   **避免万向节锁 (Gimbal Lock)**：欧拉角在特定角度（如俯仰角 90 度）会丢失一个自由度，导致锁死。四元数表示法从根本上避免了这一问题。
*   **计算高效**：相比旋转矩阵，四元数存储更紧凑，插值计算更高效。

### 4.2 为什么使用 Slerp 而不是 Lerp？
四元数表示旋转时，必须是**单位四元数**（模长为 1）。所有合法的单位四元数构成了一个 **3 维超球面 ($S^3$)**。

| 特性 | 线性插值 (Lerp) | 球面线性插值 (Slerp) |
| :--- | :--- | :--- |
| **路径** | 直线穿过球体内部 (弦) | 沿球面大圆弧 (测地线) |
| **模长** | 中间点模长 < 1 (需归一化) | 始终恒为 1 |
| **角速度** | 不均匀 (两头慢中间快) | **恒定角速度** |
| **后果** | 产生缩放伪影，速度信号噪声大 | 纯旋转，速度信号平滑 |

### 4.3 几何示意
```
       单位超球面 (合法旋转空间)
      /                         \
     /      q1 (起点)            \
    /       *                     \
   |       / \  <-- Slerp (弧面)   |  ✅ 路径短，速度匀，模长=1
   |      /   \                    |
   |     /     \                   |
   |    *-------*  <-- Lerp (弦)   |  ❌ 路径长，速度不均，模长<1
   |   /         \                 |
   |  /           \                |
    \ *             \              /
     \  q2 (终点)     \            /
      \___________________________/
```

### 4.4 代码实现
```python

# 1. 转换为 Rotation 对象
rotations_orig = R.from_quat(root_data_orig[:, 3:7])
```

### 5.2 常见技术问题及回答

**Q1: 为什么四元数插值要用 Slerp？**
> **A:** “四元数空间是非欧氏的流形（超球面）。普通的线性插值 (Lerp) 会导致插值点脱离单位球面，产生缩放伪影，且即使归一化后，角速度也会忽快忽慢。使用 **Slerp** 可以确保插值轨迹是球面上的测地线，保证**角速度恒定**。这对我们后续通过差分计算**角速度信号**至关重要，能有效减少噪声。”

**Q2: 四元数如何解决万向节锁？**
> **A:** “万向节锁是欧拉角表示法在特定角度丢失自由度的问题。**四元数表示法本身就没有万向节锁**。我们在项目中选用四元数而不是欧拉角，是为了从表示层面彻底规避这个问题。”
> *(注意：区分清楚，四元数避免万向节锁，Slerp 避免插值 artifacts)*

**Q3: 代码中的 Z 轴偏移 0.5 米是怎么确定的？**
> **A:** “这是针对特定场景的经验值调整。原始动捕坐标系地面为 z=0，但仿真中需要机器人悬空以防穿透。在实际工程中，我会将其作为配置文件参数，或者通过脚部接触检测自动校准地面高度。”
