在人形机器人 **MPC 控制框架**里，各个模块的控制频率通常不是一样的。一般原则是：

**越靠近电机，频率越高；越偏规划/优化，频率越低。**

下面是一个常见工程配置范围。

|模块|常见频率|说明|
|---|--:|---|
|电机电流环 / 力矩环|**5–20 kHz**|通常在驱动器内部完成，用户控制器不直接跑这么高|
|电机速度环|**1–5 kHz**|也多在驱动器内部|
|电机位置环|**500 Hz–2 kHz**|如果使用位置控制，驱动器或底层控制器执行|
|关节 PD / Torque Tracking|**500 Hz–2 kHz**|最靠近机器人本体的控制层，要求实时性最高|
|全身控制 WBC / QP|**200–1000 Hz**|把期望质心、接触力、足端任务转成关节力矩或关节加速度|
|状态估计 State Estimation|**200–1000 Hz**|融合 IMU、编码器、足底接触、运动学等|
|MPC 优化|**20–200 Hz**|人形机器人常见约 **50–100 Hz**|
|步态调度 / 接触序列更新|**50–200 Hz**|决定当前是左脚支撑、右脚支撑、双支撑等|
|Swing Leg Trajectory 摆腿轨迹|**100–500 Hz**|生成足端期望位置、速度、加速度|
|Footstep Planner 落脚点规划|**5–50 Hz**|高层规划，不需要太高频|
|高层速度指令 / 遥控 / 导航|**1–20 Hz**|例如给定 vx, vy, yaw rate|
|感知模块，相机/点云|**10–60 Hz**|取决于相机和算法|
|地形估计 / height map|**5–30 Hz**|一般比控制慢|

一个比较典型的人形机器人 MPC 控制架构可以这样理解：

```text
High-level command        10 Hz
        ↓
Footstep / gait planner   20–50 Hz
        ↓
MPC                       50–100 Hz
        ↓
WBC / QP                  500 Hz
        ↓
Joint PD / torque control 1000 Hz
        ↓
Motor driver current loop 10 kHz+
```

对于你之前做的那种 **Mini Cheetah / Hector 风格 MPC**，常见设置大概是：

```text
State Estimation:     500–1000 Hz
MPC:                  30–100 Hz
WBC / Convex MPC QP:  500–1000 Hz 或与控制主循环一致
Low-level PD:         500–1000 Hz
Motor CAN/CAN-FD:     500–1000 Hz 左右
```

如果是人形机器人，常见比较稳妥的配置是：

```text
主控制循环：          500 Hz 或 1 kHz
状态估计：            500 Hz 或 1 kHz
MPC：                 50 Hz
WBC/QP：              500 Hz
关节 PD/力矩控制：     1 kHz
步态调度：            100 Hz
摆腿轨迹：            500 Hz
落脚点规划：          20 Hz
```

核心原因是：**MPC 太慢，不能直接作为最底层控制器。**  
MPC 通常只负责算未来一段时间的质心轨迹、接触力、ZMP、CMP、footstep 等；真正每个控制周期稳定机器人的是 **WBC + 关节级 PD/力矩控制**。

举个简单例子：

```text
MPC 每 20 ms 算一次，也就是 50 Hz
WBC 每 2 ms 算一次，也就是 500 Hz
关节 PD 每 1 ms 执行一次，也就是 1000 Hz
```

在两个 MPC 解之间，WBC 会继续跟踪上一次 MPC 给出的参考轨迹，而不是等 MPC 每次都重新算完。

对于人形机器人，我建议你记住这个经验值：

> **MPC：50–100 Hz；WBC：500–1000 Hz；关节控制：1000 Hz 左右；状态估计：500–1000 Hz。**

如果机器人算力比较弱，比如嵌入式 CPU，MPC 可以降到 **20–50 Hz**。  
如果使用 centroidal MPC、简化接触模型，跑到 **100–200 Hz** 也有可能。  
如果是复杂 full-body MPC，可能只有 **10–50 Hz**。
